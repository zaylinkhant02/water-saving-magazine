# Every Drop Counts

**Every Drop Counts** is an interactive digital magazine about water conservation and drought preparedness in Myanmar. Created as an English project, it focuses on water scarcity in the Central Dry Zone (CDZ) and practical, long-term ways households can build resilience to drought.

The magazine combines research, data, and persuasive writing style to encourage city residents to adopt sustainable water habits.

## Features

- **Interactive magazine:** Read the publication as a page-turning digital magazine powered by StPageFlip.
- **Data and visuals:** Explore statistics and visuals about water loss and the effects of drought on agriculture.
- **Myth-busting:** Consider common assumptions about water use and conservation.
- **Interactive quiz:** Test your knowledge of which household water sources can be safely reused.

## Vercel Web Analytics

The site includes Vercel Web Analytics and Speed Insights scripts. To enable tracking:

1. Open this project in the Vercel dashboard.
2. Select **Analytics** and enable **Web Analytics**.
3. Redeploy the site.

Page-view data will appear in the Analytics dashboard after visitors use the site. Speed Insights can be enabled from its corresponding Vercel dashboard section.
