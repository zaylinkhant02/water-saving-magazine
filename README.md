# Every Drop Counts (Magazine)

An interactive digital magazine focused on water conservation and drought preparedness in Myanmar, created as an English project.

## About the Project

This publication explores water scarcity in Myanmar, specifically the Central Dry Zone (CDZ), and provides practical, long-term strategies for household drought resilience. Combining data, persuasive writing style, and interactive elements, the magazine aims to encourage city residents to adopt sustainable water habits.

## Features

- **Interactive Format:** A digital flipbook using OpenPageFlip for realistic page-turning.
- **Data Visualization:** Clean charts and statistics outlining regional water loss and agricultural impact.
- **Persuasive Writing Style:** Myth-busting sections designed to challenge assumptions.
- **Interactive Quiz:** An interactive quiz to test preparedness knowledge.

## Vercel Web Analytics

The site loads Vercel Web Analytics from `/_vercel/insights/script.js`. 

To enable tracking:
1. In the Vercel dashboard, open this project.
2. Choose **Analytics** from the sidebar.
3. Enable **Web Analytics**.
4. Redeploy the site afterward. Page views will appear in the Analytics dashboard after visitors arrive.
